Every amount is an 18-decimal integer (wei / WAD) written as a decimal string and **rounded down**.
Reference values come from 60-digit `Decimal` arithmetic floored once, so they are the exact
mathematical result to the last wei. `tests/test_vectors.py` checks that the files are reproducible
and agree with the float engine.

## Integer algorithms

**Emission (spec §3.1, §3.3)**

```
DELTA_H_WAD = floor(1e18 · (1 − (1 − 0.0005)^(1/24))) = 20838326282491
E_h         = floor(R_h · DELTA_H_WAD / 1e18)
miners      = floor(E_h · 9000 / 10000)
dev         = floor(E_h · 500 / 10000)
treasury    = E_h − miners − dev            # the split remainder goes to the treasury: nothing is lost
R_{h+1}     = R_h − E_h
```

Because DELTA_H_WAD is floored, 24 epochs emit 49,999.999999998 DIG on day 1 instead of 50,000
(−1.6e-9 DIG); the shortfall stays in the reserve. The vectors assume the whole E_h is distributed
(H > 0 for the full hour); partial hours (E_h · seconds / 3600) are a contract detail not covered here.

**VRGDA (spec §6.2)**: `p(t,n) = p0·(1−k)^(t − n/r)` with t in days (= seconds / 86400) and n the DP
units sold so far; unit j of a purchase costs p(t, n + j) (the spec's convention; Art Gobblers prices
the next token at `sold + 1`; pick one in the contract and keep it). `batch = p(t,n)·(a^q − 1)/(a − 1)`,
`a = (1 − k)^(−1/r)`, `tier = batch(DP_tier)·(1 + premium)`. Points far behind schedule underflow
to a few wei or 0 (e.g. t = 365, n = 0): useful edge cases.

**Outposts (spec §7)**: `cost(L, idx) = floor(next_level_cost_wad(L) · idx_wad / 1e18)`.

**Market open (spec §11)**

```
energy_usd = floor(kWh_wad · usd_per_kwh_wad / 1e18)
P0         = floor(energy_usd · 1e18 / genesis_miner_accrual_wad)
DIG_LP     = min(floor(pol_eth_wad · eth_usd_wad / P0), 1_000_000e18)
```

Chainlink ETH/USD has 8 decimals: scale it to 18 first. "Genesis energy spend" = kWh *purchased* during
pre-fill and genesis. Under the v0.2 tank cap a purchase may only last until Market Open + 24 h, so
purchased ≈ consumed + one day. In the simulated rows this gives P0 ≈ $0.04, against ≈ $0.12 without the cap.

**VRGDA re-anchoring (spec v0.2 §12)**

```
p(t, n)   = p0 · (1 − k)^(s_a + (t − t_a) − (n − n_a)/r)       # s_a = t_a = n_a = 0 before any change
on r → r_new at (t, n):
  s_a := s_a + (t − t_a) − (n − n_a)/r ;  t_a := t ;  n_a := n ;  r := r_new
```

Without re-anchoring, the price jumps when r changes. Cutting r by 25% with 1M DP sold moves the schedule
about 167 days, a factor of about 0.85^−167 in price. **Any contract that lets governance change r must
re-anchor this way.**
